## 🔧 IF SOMETHING GOES WRONG

| Problem | Solution |
|---------|----------|
| Black screen | Wait 10 sec, then refresh (F5) |
| No server starting | Check Node.js installed (`node --version`) |
| Port 3000 in use | Close other apps, or use port 3001 |
| JWST won't rotate | Use LEFT-click (not right-click) |
| No power values | Press F12, check console for errors |
